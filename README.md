# 重叠学习统计的可披露查询与订阅交付

这是一个面向社区老年教育运营的本地分析原型，使用合成记录演示从业务记录到运营摘要的处理。项目把记录读取、统计口径和运营判断分开，便于核对原始事实与派生结果。

## 环境与使用

需要 Python 3.11 或更高版本，无第三方依赖。运行 `python3 -m unittest discover -s tests -v` 执行测试；运行 `python3 -m learning_statistical_release.report` 查看合成数据摘要。所有记录均为本地合成数据，不包含个人信息。

## 现有行为

人群聚合产生关系约束；披露判断受同一受众历史精确结果限制；订阅交付改变之后查询的可披露空间。

当前摘要只反映样例记录的基础汇总，不用于形成个体资格或运营承诺。SQLite 数据库在调用时创建于临时目录，原始 CSV 保持不变。
